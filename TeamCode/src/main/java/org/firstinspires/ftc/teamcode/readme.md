# Project directories
- auto - autonomous code
- test_beds - scripts for testing certain things for calibration
- modules - modules used for running systems within the robot (IE: movement, turret, etc..)
- teleop - teleop code
- config - holds global config for the code so we can easily change numbers and whatnot.
